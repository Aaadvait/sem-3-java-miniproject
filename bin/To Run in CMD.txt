-> To Run the Program (Windows CMD)

1. Open Command Prompt and navigate to the "src" folder:
   cd E:\sem-3-java-miniproject-main\sem-3-java-miniproject-main\src

2. Set your JavaFX path (adjust if your SDK is located elsewhere):
   set FX=C:\javafx-sdk-27\lib

3. Compile the code:
   javac --module-path %FX% --add-modules javafx.controls,javafx.fxml,javafx.graphics,javafx.swing Main.java

4. Run the game:
   java --module-path %FX% --add-modules javafx.controls,javafx.fxml,javafx.graphics,javafx.swing Main
